# 결과

담당: 분석 · 개발

보고서에 쓴 요약 결과와 그림입니다. 모두 9층 기준이며, 층별 결과는 3 · 5 · 9 · 15 · 20 · 25층입니다.

| 파일 | 내용 |
|---|---|
| `solar_result_summary.csv` | 입면별 창 일사 감소율 (냉방기 · 난방기) |
| `Horizontal_Winter_Summary.csv` | 수평 루버 겨울 일사 손실 |
| `Floor_Solar_Result_Table.csv` | 층별 창 일사량 |
| `Floor_Effect_Summary.csv` | 층별 효과 요약 |
| `Cutoff_Sweep.csv` | 컷오프 각도 0~90° 민감도 |
| `Weather_Variability_Summary.csv` | 맑은 날 · 흐린 날 비교 |
| `Energy_EnergyPlus_vs_Estimate_v9.csv` | EnergyPlus 냉난방 에너지와 추정값 비교 |
| `EnergyPlus_Calibrated_to_Radiance.csv` | Radiance에 맞춘 EnergyPlus 보정 결과 |
| `Protective_Glass_Radiance.csv` | 보호 유리 유무 비교 |
| `figures/` | 보고서 그림 (차트, Unity 시연 화면, 웹 지도) |
