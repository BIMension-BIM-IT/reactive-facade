- `0_안내` 시트에 시트 구성, 핵심 숫자, 바꾼 내역이 있습니다.
- 숫자는 팀 Radiance 1784 1~28층 평균 일사량 기준이며 웹 검토 도구와 0.05% 안에서 같습니다.
- 노랑 · 주황 칸(가정값)을 바꾸면 7~13번 시트가 함께 바뀝니다. 파일을 열면 엑셀이 다시 계산합니다.
- `15_웹도구` 시트: 시연 순서, 인쇄 보고서 구성, 웹 "에너지 구성" 차트와 같은 값, 남은 문제.
