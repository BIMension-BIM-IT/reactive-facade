# 웹 도구

담당: 총괄 · 웹 · 보고서

웹 코드는 아래 저장소에서 관리합니다. 여기에는 복사하지 않습니다.

- 사이트: https://emmiart7-png.github.io/bimention-bim-it-teamproject/
- 계산 엔진은 [docs/반응형외피_경제성자료.xlsx](../docs/) 와 같은 식입니다 (엑셀 검증 모드로 0.05% 안에서 일치).

## 쓰는 순서

1. **건물 고르기**: 주소나 건물 이름으로 찾거나 지도에서 건물을 클릭합니다. 외곽선 · 층수 · 주소가 나옵니다.
2. **입면 만들기**: "이 건물로 입면 만들기"를 누르면 입면이 북(12시)부터 시계방향으로 생깁니다. 북쪽 ±45° 입면은 기본으로 루버를 달지 않습니다.
3. **루버 달기 · 떼기**: 루버 시뮬레이션의 평면도에서 입면 이름표를 누릅니다 (실선 = 루버 있음 · 점선 = 없음).
4. **하루 재생**: 날짜(춘분 · 하지 · 추분 · 동지)와 시각을 바꾸거나 재생합니다. 네이버 1784는 Unity, 다른 건물은 웹 3D로 보입니다.
5. **결과**: 누적 순이익, 요약 카드, 에너지 구성, 대안 비교, 입면별, 연간 운영 히트맵.
6. **보고서**: "인쇄 / PDF" 버튼을 누르면 보고서용 화면을 자동으로 찍은 뒤 A4 3쪽으로 인쇄합니다 (Ctrl+P 말고 버튼으로, Unity는 10~20초).

## 인쇄 보고서 3쪽

| 쪽 | 내용 |
|---|---|
| 1 | 검토 대상, 루버 시뮬레이션 (평면도 + 화면), 보고서용 화면 캡처 (냉방 효과가 가장 큰 입면의 하지 닫힘 · 열림, 하지 · 동지) |
| 2 | 누적 순이익, 요약 카드, 에너지 구성, 대안 비교 |
| 3 | 입면별, 연간 운영 히트맵 |

## 남은 문제

- Unity 1784 장면이 180° 돌아가 있음 → 시각화 담당 수정본으로 다시 빌드 예정
- Unity 시작 때 NullReferenceException 2개 (화면은 정상)
