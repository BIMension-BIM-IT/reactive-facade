## 화면 (10/16)

왼쪽 사이드바(건물 · 설정) + 오른쪽 큰 루버 시뮬레이션 화면입니다.

- **건물**: 주소 · 건물 이름 검색 또는 지도 클릭 → **입면 만들기**. 입면은 북(12시)부터 시계방향, 북쪽 ±45° 입면은 기본으로 루버 없음.
  "정보 수정" 을 펴면 지상층수 · 층고 · 창면적비 · 짧은 변 제외(기본 10 m)를 바꿀 수 있습니다. "기본값" 은 네이버 1784 로 돌아갑니다.
- **설정**: 날짜(춘분 · 하지 · 추분 · 동지), 시각, 재생 (▶ = 0.5배속, ▶▶ = 빠르게), 빛반사 보기 (끄기 | 켜기), 평면도(입면 이름을 눌러 루버 달기 · 떼기).
- **루버 시뮬레이션 화면**: 외관 · 실내 · 나란히, 북 · 동 · 남 · 서 · 전체 (입면 정면 보기).

| | 네이버 1784 | 지도에서 고른 건물 |
|---|---|---|
| 외관 | Unity | 그 건물 웹 3D (주변 건물 · 지형) |
| 실내 | Unity 1784 실내 | Unity 1784 실내 (예시) |
| 나란히 | 1784 외관 + 실내 | 왼쪽 웹 3D 외관 + 오른쪽 1784 실내 |
| 빛반사 보기 | Unity GlareSim (태양 궤적 · 반사광) | 웹에서 유리 반사 계산 → 주변 건물 벽 · 지붕에 노랑 ~ 주황 면 |

- 화면 돌리기: 외관 = 마우스 왼쪽 끌기 · 휠. 1784 실내는 지금 오른쪽 끌기 (다음 Unity 빌드에서 외관과 같게 바꿀 예정, 휴대폰 터치 포함).
- 결과: 누적 순이익, 요약 카드, 에너지 구성, 대안 비교, 입면별, 연간 운영 히트맵.

## 인쇄

- **인쇄**: A4 3쪽 요약. 버튼을 누르면 Unity · 웹 3D 화면을 자동으로 찍은 뒤 인쇄 창이 열립니다 (Ctrl+P 말고 버튼으로, Unity 는 10~20초). 쪽마다 약 13% 여유를 둬서 브라우저 여백 · 용지가 조금 달라도 3쪽입니다.
- **상세 인쇄**: 종합보고서 양식 약 16~17쪽.

| 쪽 | 내용 |
|---|---|
| 1 | 검토 대상, 루버 시뮬레이션 (평면도 + 화면), 보고서용 화면 캡처 (냉방 효과가 가장 큰 입면을 가운데 확대: 하지 닫힘 · 열림, 하지 · 동지) |
| 2 | 누적 순이익, 요약 카드, 에너지 구성, 대안 비교 |
| 3 | 입면별, 연간 운영 히트맵 |
